# ToolBox Development

Power Platform ToolBox ships as two separate host applications, each with its own codebase. Pick the track that matches what you want to contribute to. {{ className: 'lead' }}

## Overview {{ anchor: true }}

- **Desktop App** — the original Electron application, distributed as Windows/macOS/Linux installers.
- **VS Code Extension** — a newer host that runs tools inside VS Code, distributed via the VS Code Marketplace.

Both hosts implement the same tool-facing APIs (see [Tool Development](/tool-development)), but they are built, tested, and released independently as separate repositories.

## Desktop App {{ anchor: true }}

Electron + TypeScript + Vite. Repository: [desktop-app](https://github.com/PowerPlatformToolBox/desktop-app).
